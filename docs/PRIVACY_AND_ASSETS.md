# Clean sharing rules

The distribution is built from a reviewed file allowlist. It does not copy the original user's raw media, finished videos, transcripts, face photos, generated expressions/covers, personal preferences/account history, social-scrape data, .env, API tokens, browser data, downloaded creator examples, venv, caches or purchased asset packs.

The **only** footage/transcript included is the synthetic demo, authored for this kit, and its illustrative timings. The placeholder source image contains text/geometric boxes and no person. Source transcript metadata uses a relative path, and no generated job HTML with laptop file:// URLs is shipped. Packaging audits text for private names/handles, absolute machine paths and key-like tokens and checks source/demo hashes against its explicit distribution inventory.

Public assets are bundled Inter/Playfair Display fonts with upstream OFL notices, and the kit's procedural logo/stills/sounds/test bed. The optional official segmentation model is downloaded on the recipient's machine, with source and checksum recorded; it is not copied from someone's model cache. Whisper, npm dependencies and HyperFrames' Chrome browser are installed by the recipient; their licenses/terms remain upstream.

Use assets/broll/commons_sources.json for future Commons downloads. Metadata alone does not grant permission; follow the actual file-page license, attribution, and restrictions. Verify logos against official brand sources. Add your own licensed music and speech recordings. Do not redistribute commercial packs or another creator's image/portrait.

Once you import your own footage, this becomes a private working folder. The clean package helper rejects altered distribution files and excludes any new material; it is not a blanket guarantee for arbitrary modifications. Send the original clean ZIP when possible. If deliberately customizing the method for sharing, review the diff, create a new audited distribution manifest and inspect every archive member before sending.
