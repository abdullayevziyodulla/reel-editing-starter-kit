# Plan and data reference

All file paths in plans are relative to this kit root. JSON uses ordinary double quotes. UTF-8 text supports Uzbek `o'`, `g'`, `sh`, `ch`; preserve the transcript's spelling. All coordinates refer to the normalized 1080×1920 composition unless otherwise stated. Preview resolution does not change plan coordinates.

## Transcript

`transcript/<clip>/segments.json`:

```json
{
  "clip": "raw/my_clip.mp4", "duration": 8.0,
  "fps": 30, "fps_str": "30/1", "width": 1080, "height": 1920,
  "segments": [
    {"i": 1, "start": 0.2, "end": 2.5, "text": "Your exact words."},
    {"i": 2, "start": 3.0, "end": 7.0, "text": "The next sentence."}
  ]
}
```

`words.json` is a list of `{"seg":1,"w":"Your","start":0.2,"end":0.5}` entries in **raw source seconds**. A segment with blank text needs no words. Do not use fabricated demo word times for a real clip. `audio16k.wav` is required for alignment, but rendering with complete existing data needs only the video, segments/cuts/words/plans/assets.

`cuts.json`: `keep` unique IDs in playback order; `captions:false`; optional `edits` object keyed by string ID, e.g. `{"2":{"start":3.1,"end":6.9}}`. Missing IDs, repeats, empty pieces and invalid spans are rejected. `pieces.json` is generated, not hand-written: each piece has i/start/end/text/speech_start/speech_end. Its start/end are raw source coordinates. `timeline.json` is generated by toolkit.py; it adds sorted mapped words and output segment bounds.

## Dynamic edit.json

| Field | Meaning |
|---|---|
| base | Path to output/<clip>_clean.mp4, or a deliberately prepared extended base |
| layout | Ordered, nonoverlapping intervals covering the full base |
| face_center | [x,y] zoom focus, default [540,800] |
| split_face_top | Source crop y for speaker below a 960px split; calibrate per source |
| highlight | Keywords highlighted in captions, matched case-insensitively |
| caption_style | size, accent hex, pill boolean, font filename; face_y/split_y/full_y caption centers |
| grade | FFmpeg filter string; default mild contrast/saturation/brightness |
| music | null or {file, db, start}; start is offset INTO music, not output delay |
| sfx | [{t,file,db,max?}]; t is output placement; max limits source duration |
| graphics | Animated overlays with type/start/end plus fields below |
| intro_duration | Optional caption offset only; create an extended base separately |

Layout `{"start":0,"end":3,"mode":"face","zoom":[1.03,1.08]}`. Face zoom values must be ≥1. `split` / `full` need `broll`; optional `kb:[1,1.08]`, `focus:[.5,.5]`, `from:0` media offset and `enter:false` to disable entry punch. GIF/video loops if scene length exceeds its source.

The captions group up to three words, break at punctuation/segment changes, and hold across a short gap. The default font aliases resolve to bundled Inter. A font filename such as `Inter.ttf` can be supplied explicitly. The default caption center in face mode is 84.5% of canvas height, but mouth location varies—inspect it.

| Graphic type | Required fields beyond type/start/end | Optional |
|---|---|---|
| title | text, sub, logo | y; fixed hook badge/eye motif |
| text_hook | text (newline allowed) | size, y, color |
| hud | none | decorative generic tracking frame; do not imply real telemetry |
| logo_card | logo, tag | y |
| stamp | text, kind (x/check) | y |
| comment | text | type_at local offset, per_char, placeholder, y |

## HyperFrames hf_plan.json

| Field | Meaning |
|---|---|
| base | Clean/extended base video path |
| name | Human-readable edit name; final filename is chosen in finalizer |
| theme | light (default) or dark |
| caption_y | Center y in top/card mode, e.g. 900 |
| caption_style | mono, capsule, or default mixed sans/italic serif |
| emphasis | Lowercase keywords using italic serif in default style |
| layout | Full coverage with top or face modes, start/end/zoom |
| speaker | Optional segmented head-breakout config; recommended for real card edits |
| cut_src_top | Fallback arched crop y when speaker is omitted |
| face_center | [x,y] full-frame zoom focus |
| scenes | HTML card scenes described below |
| auto_sfx | true by default; false disables generated UI timing sounds |
| music, sfx, grade | As above; finalization still required |
| intro_duration | Shift captions only; must already be reflected in base/visual times |

`speaker` fields: scale .68, head_top_src 370, head_y 1015, card_top 1130, card_w 720, radius 64. These values are an example. `head_top_src` is the raw head-top coordinate AFTER scaling the original video to 1080×1920; `head_y` is its intended output position. With scale .68, scaled video width is about 734px, so 720px card fits inside. Above-card person mask uses MediaPipe. Calibrate source geometry, entry zooms and card placement to avoid hair clipping/black edges. Head segmentation needs `assets/models/selfie_segmenter.tflite`.

Every scene has type/start/end. Unless explicitly marked otherwise, inner element times are **absolute output seconds**. Typical scene center is [540,465], above captions/speaker. Template example scenes use 2s slots only for a synthetic demo; use actual speech lengths.

| Scene | Fields |
|---|---|
| counter | logo, number, unit, title, count_at |
| window | media, title; optional w, aspect, cy, from, cursor [{t,from:[x,y],x,y}] |
| tiles | items [{t,img,label,icon?,pos?}], 4-column layout |
| chat | title, q, a, q_t0, q_t1, a_t0, a_t1 (each typing interval must increase) |
| stack | cards [{t,kind:"github",owner,repo,chips:[...]}, or {t,kind:"logo",img,h?,tag?}] |
| strike | title, sub, strike_at |
| checklist | title, rows [{t,icon,name,desc}], at least one row |
| converge | window media/title fields, chips_at, merge_at, chips [{x,y,label}] |
| comment | title, placeholder, text, type_at ABSOLUTE, per_char >0, send_at |

For window/converge, HyperFrames owns persistent timed media clips. Python converts video/GIF b-roll into browser-compatible, scene-length MP4s (respecting `from` and looping) and copies stills/images into the generated project. HTML holes describe animated media geometry only; there is no Python browser-capture or media-paste loop. Project media paths are relative and local. Avoid HTML-looking text or quote characters in filename metadata; use ordinary descriptions and safe local paths.

Auto sounds: card entry → pop/ui_appear, item/stack entry → pop, row/cursor → click, chat/CTA → keyboard, strike → swipe, converge → whoosh, checklist completion → sparkle, return to face → whoosh. Assets are generated in this kit; replace them with licensed sounds if desired, preserving paths or writing explicit sfx. Sound delays use the same output timeline as visuals.

HyperFrames frames: `--frames 0.5,3.2` → transcript/<clip>/check/hyperframes/frame-*.png plus contact-sheet.jpg. `--prepare` builds/lints transcript/<clip>/hyperframes/ for direct Studio/HTML editing. `--workers` defaults to 1. `--preview` → draft capture followed by half-resolution video output (capture remains full-size). Full output is `output/<clip>_nick.mp4`; it is never automatically promoted to final/ in this kit. Use `toolkit.py finalize`.

## Limits

- Composition is fixed at 1080×1920 / 30fps; no horizontal export or editing-app timeline export.
- Alignment is estimated, not forced-alignment ground truth.
- Some card dimensions/font sizes are fixed; very long text can overflow. Shorten labels or inspect and adjust runtime CSS deliberately.
- Dynamic title contains a generic eye motif. Use text_hook/logo_card instead for unrelated subjects.
- The dynamic compositor stores decoded GIF/video frames in RAM. HyperFrames manages its own media extraction/cache; use one capture worker on memory-constrained laptops.
- No color LUT manager, masked transitions, multiline karaoke word highlighting or Premiere/Resolve export is implemented.
